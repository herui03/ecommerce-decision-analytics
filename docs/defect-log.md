# Defect log (2026-09 upgrade)

Every entry is a defect that was actually observed, with where it was found and the evidence.
Commit hashes in this file and in `docs/evidence.md` refer to the private development repository; the public
repository starts from a single reviewed snapshot of it. "Baseline" defects existed on `main` at `b29b1ed`; "upgrade" defects were introduced and caught during
this work (by independent review from Codex, by the test suite, or in the real-browser run). Numbers in
this file are reproducible from the files named in the Evidence column.

## Known limitations that are not defects

- The historical extracts do not store valid-value counts for per-month means, state-level delivered/late
  counts or `orders_with_items` for state/payment cells. The dashboard reports multi-cell values as
  unavailable, or infers an integer only when exactly one value reproduces the exported ratio. The one
  unidentified cell (payment, 2018-08, `not_defined`: NULL GMV) is shown as unavailable.
- The corrected lead design, applied to the real dates, would train on about one month of mature labels
  (contacts 2018-01-01 to 2018-01-30 for an as-of of 2018-05-01). It has not been run on real data.
